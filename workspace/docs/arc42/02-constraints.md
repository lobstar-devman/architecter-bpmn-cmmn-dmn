# 2. Constraints

## Technical Constraints

- Laravel 13, PHP 8.4+.
- PostgreSQL database.
- Distributed as a Composer package providing a drop-in Laravel Model
  (see [Section 1](01-introduction-and-goals.md)).

## Organizational Constraints

There are no Organizational Constraints.

## Conventions

- **Style:** [Laravel Pint](https://laravel.com/docs/pint) (PSR-12-based).
- **Testing:** [Pest](https://pestphp.com/).
- **Static analysis:** PHPStan via [Larastan](https://github.com/larastan/larastan).
