# Architecture Documentation

This site is generated from the project's sources of truth (BPMN/CMMN/DMN
XML, Structurizr DSL, OpenAPI, JSON Schema, and Mermaid text). It follows
the [arc42](https://arc42.org) template, with system-structure diagrams
following the [C4 model](https://c4model.com).

**Nothing on this site is hand-edited.** Every page and every diagram is
regenerated by the CI pipeline whenever its source of truth changes. To
change something, edit the source of truth — see
[Sources of Truth](sources-of-truth/index.md) for where each one lives.
